BAB 1Pengantar Jaringan & Model Lapisan

1.1 Model OSI dan TCP/IP

Konsep dasar

Konsep

Enkapsulasi adalah proses menambahkan header (dan kadang trailer) pada data saat turun dari lapisan atas ke lapisan bawah. Setiap lapisan hanya membaca header miliknya sendiri. [2]

Model OSI membagi komunikasi menjadi tujuh lapisan, sedangkan TCP/IP menyederhanakannya menjadi empat. Pemetaan keduanya sering keluar di soal [1].

📦 Perumpamaan

Enkapsulasi seperti mengirim barang: kamu masukkan buku ke kotak (data), kotak ke kardus (segmen), kardus ke palet (paket), lalu palet ke kontainer (frame). Kurir hanya membuka kontainer, bukan buku di dalamnya.

Rumus

Throughput efektif dengan overhead header:

$$\eta = \frac{L}{L + H} \times 100\%$$
SimbolArtiSatuan
LUkuran payloadbyte
HTotal overhead headerbyte
ηEfisiensi pengiriman%

⚡ Rumus Cepat

$H_{total} \approx 20 + 20 + 14 = 54$ byte untuk TCP/IPv4 tanpa opsi.

Valid hanya jika tidak ada opsi TCP/IP dan tidak ada VLAN tag.

🎯 Kata Kunci Hafalan

  • OSI: Physical, Data Link, Network, Transport, Session, Presentation, Application.
  • TCP/IP: Network Access, Internet, Transport, Application.
  • Header IPv4 minimum 20 byte; TCP minimum 20 byte; Ethernet 14 byte.

⚠️ Jebakan

Lapisan Transport pada TCP/IP dipetakan ke dua lapisan OSI (Transport dan Session), bukan satu. Soal sering meminta pemetaan yang tepat.

BAB 2Lapisan Transport

2.1 TCP vs UDP

TCP menyediakan pengiriman andal berurutan, UDP tidak. Pilihan bergantung pada apakah aplikasi mentoleransi kehilangan data demi latensi rendah [3].

Contoh soal

Soal Tinggi

Sebuah aplikasi mengirim 1.000 byte payload di atas TCP/IPv4 tanpa opsi. Berapa efisiensi pengirimannya?

Jawaban

  1. Hitung overhead: Ethernet 14 + IP 20 + TCP 20 = 54 byte.
  2. Substitusi ke rumus: $\eta = 1000 / (1000 + 54)$.
  3. $\eta = 1000 / 1054 \approx 0{,}9488$.
  4. Ubah ke persen: $0{,}9488 \times 100\% \approx 94{,}88\%$.

Jawaban akhirη ≈ 94,88%

Soal tingkat sedang

Soal Sedang

Mengapa UDP lebih cocok untuk streaming video dibanding TCP?

Jawaban

  1. TCP mengirim ulang segmen yang hilang, sehingga menambah latensi.
  2. Pada video, frame yang terlambat sudah tidak berguna.
  3. UDP tidak melakukan retransmisi, jadi latensi tetap rendah.

Jawaban akhirUDP dipilih karena retransmisi TCP menambah latensi tanpa manfaat bagi frame yang sudah lewat.

Soal tingkat rendah

Soal Rendah

Sebutkan nomor protokol IP untuk TCP dan UDP.

Jawaban

  1. Lihat field Protocol pada header IPv4.
  2. TCP = 6, UDP = 17.

Jawaban akhirTCP = 6, UDP = 17.
