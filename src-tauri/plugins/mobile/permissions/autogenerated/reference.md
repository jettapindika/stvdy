## Default Permission

The mobile plugin's commands: scheduling the background sync, running one pass, and
filing a shared file.

#### This default permission set includes the following:

- `allow-mobile-scheduler-register`
- `allow-mobile-background-sync`
- `allow-mobile-share-intake`
